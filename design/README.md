# Design documents

The documents T9Sim v2 was built FROM, copied at publish time by
`tools/make_public.py` from the working repository, where they are
still maintained. They are not edited here: this directory is
rebuilt from scratch on every publish, so an edit made here is lost
at the next one.

| File | What it is |
|---|---|
| `T9Sim_Specification_v2.md` | the specification v2 is built from |
| `T9Sim_Rebuild_Plan_v2.md` | the plan: 7 stages, the gates, what is deferred |
| `T9Sim_Symbol_Plan.md` | the notation authority |
| `T9Sim_DGP_Node_Register.md` | the 78 nodes, one law and one type each |

The `.docx` and `.xlsx` files are the same documents in the form
they are read and reviewed in.
